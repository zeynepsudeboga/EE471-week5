  What it does
  - app.py: loads ../.env with python-dotenv and serves the page on port 5001.
    POST /api/tts checks the text (not empty, at most 1000 characters) and the
    voice, then synthesizes with audio_config=None and sends result.audio_data
    back as a WAV. If Azure cancels, it returns 502 with the cancellation reason
    and Azure's error details.
  - Voices: besides the two you asked for (tr-TR-EmelNeural and
    en-US-AvaMultilingualNeural), I added tr-TR-AhmetNeural and
    en-US-AndrewMultilingualNeural so each language has a male and a female
    voice. They're listed in the VOICES dict in app.py if you want to change
    them.
  - The page: has a text box with a character counter, a voice dropdown and a
    "Convert" button. The audio plays in an <audio> player with a "Download"
    link for speech.wav. Errors show in a red box.
  - Structure for the next branch: the TTS markup is in its own <section 
    id="tts"> and the JS and CSS use tts- prefixes. That way the speech-to-text
    branch can add its own section to the same four files without clashing.

  How to run it
  cd ~/EE471-week5
  source .venv/bin/activate          # flask, python-dotenv, 
  azure-cognitiveservices-speech are already installed
  python Week-5-Task-1/app.py
  Then open http://localhost:5001.

  On a fresh machine, run pip install flask python-dotenv 
  azure-cognitiveservices-speech first. The repo has no requirements.txt and I
  didn't add one so I'd stay inside the folder. .env is already in .gitignore,
  so the key won't be committed.
