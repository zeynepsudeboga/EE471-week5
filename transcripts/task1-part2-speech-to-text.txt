  How it works:
  - app.py: POST /api/stt checks the input, saves the upload in a temporary

    joins the recognized pieces. The temporary folder and both files are deleted
    afterwards. The key is read from the root .env and stays on the server.
  - Reaching the end of the file also counts as "canceled" in the Speech SDK, so
    only a real Azure error gives 502. An empty transcript gives 422.
  - The page: pick the language, then either upload a file or use Start / Stop
    to record. You can play the recording back before clicking "Send recording".
    Errors show in a red box and the transcript in a box with a Copy button.
  - Safari records MP4 instead of WebM, so the page sends Safari recordings as
    .m4a.
